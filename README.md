* Built a text summarization system in Python, using Pegasus-Large and Pegasus-ArXiv language models for summarizing scientific papers.
* Utilized PyTorch, NLTK, Pandas, and Hugging Face transformers for data processing and model operations
* Engineered a comprehensive data processing pipeline, including sentence chunking and batch processing, improving data flow and computational efficiency
* Evaluated models using ROUGE metrics; the base model outperformed the fine-tuned model in precision and F-measure
